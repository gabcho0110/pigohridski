Първоначална настройка на Firebase
  1. Firebase Console → Authentication → Sign-in method → включете Email/Password.
  2. Създайте потребител в раздел Users (имейл и парола).
  3. Realtime Database → Rules → поставете правилата от README (раздел „Правила“).
  4. Върнете се тук и влезте с имейла и паролата на администратора.

Подробно описание има във файла README.md в хранилището.
